Components/AI · Copilot

Copilot · Day 08 · Any time

Ask across all four.

A conversational assistant that calls all four models as tools, sees only what you can see, and changes nothing until you press Confirm.

Component
SprintIQ Copilot
Owner
Group
ProblemDesignToolsExampleSafetyLimitations
01 · Problem

Four models, many screens

Each model lives on the screen for the decision it informs: estimates on stories, velocity on sprints, rankings on tasks, cost and risk on the sprint. A scrum master's real questions cut across all of them: Is this sprint over-committed? Who should pick up the blocked story? Will we go over budget?

Answering them means opening several screens and combining the numbers by hand.

02 · Design

An agent loop that proposes, never acts

The Copilot is a hosted LLM with tool calling, running inside the Spring Boot backend. Every tool calls the same application services the screens use, inside the user's own tenant and permissions, so it can only see what the user can see.

It may read freely, but it cannot write. A change becomes a proposal card whose summary is written by the server, not the model, and nothing happens until a person presses Confirm. Proposals expire after 24 hours.

The question

The user asks in plain language; the last 20 turns give context.

The model chooses tools

Only tools the user has permission for are offered at all.

Tools run

Up to six rounds of tool calls, each checked for permission again on execution.

Answer with figures

Figures come from the models, with their ranges and caveats.

Proposal card

Any change is a proposal with a server-written summary.

A person confirms

Confirm runs the action through the normal permission checks; Dismiss discards it.

03 · Tools

Thirteen tools, five of them models

Every tool declares the permission it needs; tools the user lacks are never offered to the model.

05 · Safety

Why it's safe to let it read

  • Same permissions as the user. Tools run inside the user's tenant and role; another user's conversation returns not-found.
  • Prompt injection can only propose. Task titles and comments reach the model only as tool data. The worst an injected instruction can do is create a proposal, which a person must still confirm.
  • Off by default. The Copilot sends the figures it looks up to the LLM provider, so it stays disabled until an organisation adds its key.
  • Every step is visible. Each answer lists the tools it called and whether they succeeded.
06 · Limitations

What it doesn't do yet

  • Answers arrive as a whole turn; there is no streaming yet.
  • It lives on its own page rather than beside the board.
  • Its answers are only as good as the models it calls; it repeats their caveats rather than hiding them.
